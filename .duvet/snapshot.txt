    TEXT[!MUST]:       stored in the Authentication Section of each outgoing BFD Control
    TEXT[!MUST]:       packet.

    TEXT[!MUST]:       The Auth Len field MUST be set to the proper length (4 to 19
    TEXT[!MUST]:       bytes).
    TEXT[!MUST]:       The password is a binary string, and MUST be 1 to 16 bytes in
    TEXT[!MUST]:       length.
    TEXT[!MUST]: For interoperability, the management interface by which
    TEXT[!MUST]:       the password is configured MUST accept ASCII strings, and SHOULD
    TEXT[!MUST]:       also allow for the configuration of any arbitrary binary string in
    TEXT[!MUST]:       hexadecimal form.
    TEXT[!MAY]: Other configuration methods MAY be supported.
    TEXT[!MUST]:       If the received BFD Control packet does not contain an
    TEXT[!MUST]:       Authentication Section, or the Auth Type is not 1 (Simple
    TEXT[!MUST]:       Password), then the received packet MUST be discarded.
    TEXT[!MUST]:       If the Auth Key ID field does not match the ID of a configured
    TEXT[!MUST]:       password, the received packet MUST be discarded.
    TEXT[!MUST]:       If the Auth Len field is not equal to the length of the password
    TEXT[!MUST]:       selected by the key ID, plus three, the packet MUST be discarded.
    TEXT[!MUST]:       If the Password field does not match the password selected by the
    TEXT[!MUST]:       key ID, the packet MUST be discarded.
    TEXT[!MUST]:       Otherwise, the packet MUST be accepted.

    TEXT[!MUST]:       management interface by which the key is configured MUST accept

    TEXT[!MUST]:       packet.

    TEXT[!MUST]:       which MUST NOT be carried in the packet).

    TEXT[!SHOULD]:    since it is no longer required to maintain previous session state)

  SECTION: [Operational Considerations](#section-7)
    TEXT[!MUST]:    When BFD is used across multiple hops, a congestion control mechanism
    TEXT[!MUST]:    MUST be implemented, and when congestion is detected, the BFD
    TEXT[!MUST]:    implementation MUST reduce the amount of traffic it generates.
    TEXT[!SHOULD]:    As such, a congestion control algorithm SHOULD be used even across
    TEXT[!SHOULD]:    single hops in order to avoid the possibility of catastrophic system
    TEXT[!SHOULD]:    collapse, as such failures have been seen repeatedly in other
